#Bit Shift Demo (C言語: 論理シフトと算術シフトの比較)
C言語における論理右シフトと算術右シフトの挙動の違いを、ビットパターン（2進数）と実際の数値（10進数）を通して視覚的に比較・確認するためのプログラムです。

📌 概要
C言語で負の数に対して右シフト（>>）を行う際、コンパイラや環境によって「論理シフト（上位に0が埋まる）」になるか「算術シフト（符号ビットが維持される）」になるかが異なります（C言語の仕様上、負数の右シフトは実装依存）。

このプログラムでは、それぞれの挙動を明示的に実装・比較することで、ビット演算の仕組みを直感的に学べるようにしています。

🛠 主な関数
print_bits(int n)

整数を32ビットの2進数表現に変換し、4ビットごとにスペース区切りでコンソールに出力します。

logical_shift_right(int value, int shift)

一度 unsigned int（符号なし整数）にキャストすることで、強制的に論理右シフト（上位に常に0を埋める）を行います。

arithmetic_shift_right(int value, int shift)

符号付き整数のまま右シフトを行い、算術右シフト（符号ビットを維持する）を行います。

🚀 実行結果のイメージ
-16（32ビット環境における2進数表現で、全ビットが1で埋まり最後に 0000 が続く状態）を 2 ビット右シフトした場合の出力例です：

Plaintext
元データ:      11111111 11111111 11111111 11110000 
値: -16

論理シフト後:  00111111 11111111 11111111 11111100 
値: 1073741820 (上位に0が埋まるため正の大きな数になる)

算術シフト後:  11111111 11111111 11111111 11111100 
値: -4 (符号が維持される)
論理シフト: 上位に 0 が入るため、負の数が非常に大きな正の数に変化します。

算術シフト: 最上位ビット（符号ビット）の 1 が維持されるため、 -16 を 4 で割った値（-4）になります。

⚙️ 使い方（ビルドと実行）
GCCなどのC言語コンパイラを使用してビルド・実行できます。

Bash
# コンパイル
gcc -o bit_shift_demo main.c

# 実行
./bit_shift_demo
